# data_science_portfolios
Repositori `data_science_portfolios` merupakan salah repositori portofolio yang mencakup berbagai portofolio sains data yang sudah dikerjakan, sedang dikerjakan, dan akan dikerjakan. Repositori ini sangat cocok untuk data scientist pemula, menengah, dan mahir yang ingin mempelajari struktur portofolio data science secara lengkap, padat, dan jelas.
