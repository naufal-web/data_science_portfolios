# Data Science Portofolios by Naufal Web
Repositori _data_science_portfolios_ merupakan salah repositori portofolio yang mencakup berbagai portofolio sains data yang sudah dikerjakan, sedang dikerjakan, dan akan dikerjakan. Repositori ini sangat cocok untuk data scientist pemula, menengah, dan mahir yang ingin mempelajari struktur portofolio data science secara lengkap, padat, dan jelas.
Berikut portofolio yang sedang dikerjakan, antara lain 

1. _Time-series town-specific resale flat price fluctuation prediction for Singapore's Housing Development Board projects sustainability_
2. _Dubai apartments neighborhood classification for UAE's Emaar Property PJSC future serviced apartments project planning_
3. _Customer transaction value prediction as data-driven convenience store product availability recommendation tool development insight_
4. _Multi-product classification as an early foundation for simultaneous, sustainable, and profitable product restocking decision support_
